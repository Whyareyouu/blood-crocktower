# Кровь на часовой башне

Веб-версия настольной игры. Проект находится на этапе подготовки инфраструктуры.

Стек: Next.js и TypeScript, Go, GORM, PostgreSQL, WebSocket.

Разработка ведётся по Gitflow с ветками `main`, `develop`, `feature/*`,
`release/*` и `hotfix/*`. Сообщения коммитов следуют Conventional Commits;
описания в заголовке, теле и footer пишутся на русском языке.
