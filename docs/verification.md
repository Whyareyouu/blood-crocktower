а не игровые механики.

| Проверка | Результат |
| --- | --- |
| `pnpm test:conventions` | Пройдены 14 проверок, включая русские merge-коммиты, тело и BREAKING CHANGE |
| `pnpm lint` | Пройдено |
| `pnpm typecheck` | Пройдено |

`pnpm check` объединяет тесты соглашений, lint, typecheck, тесты Go и go vet.
Проверки чтения глобальных и клиентских инструкций выполнены отдельно.

## Не проверено в текущем окружении

- Docker CLI не обнаружен: Docker-образы и полный Compose-стек локально
  не запускались. Подготовлен отдельный CI job сборки и запуска контейнеров.
- PostgreSQL не запущен: `TestMigrationAndReadiness` явно пропущен без
  `TEST_DATABASE=1`. CI поднимает отдельный PostgreSQL и включает этот тест.
- Визуальная проверка в браузере, мобильные сценарии и игровые сценарии
  относятся к следующим этапам; HTTP smoke-тест их не заменяет.
- Удалённый репозиторий не настроен, поэтому CI на хостинге ещё не выполнялся.

Production-сборка и HTTP smoke-тест выполнены вне ограниченного sandbox:
внутри него создание служебного каталога Next.js и локальные HTTP-запросы
блокировались. Это не обход проверок приложения.
